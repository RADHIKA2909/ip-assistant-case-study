# Evidence-Grounded IP Assistant: product case study

An interactive AI product management case study: a proposed AI assistant for document-heavy patent / IP workflows, with an evidence-first, expert-reviewed prototype.

This is an independent, illustrative concept. It does not represent any company's implementation.

```bash
npm install
npm run dev        # http://localhost:5173
npm run typecheck
npm run lint
npm test
npm run build
```

Architecture, design system, prototype state model and contribution rules are in [CLAUDE.md](./CLAUDE.md).
